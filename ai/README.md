# FIDALLY AI and Voice

This folder holds the plan for FIDALLY's voice conversation.

## How a conversation works

1. The microphone records the user's voice.
2. Speech-to-text turns the voice into text.
3. A language model understands the request and writes a reply.
4. If the user asks to save something, FIDALLY asks for confirmation first.
5. Text-to-speech reads the reply out loud.
